# 300개 Mock 완성 화면

## 현재 입력

- 기존 25개를 포함하여 총 300개: AWS 100, Azure 100, GCP 100.
- 기존 25개의 정책 구성·보안 메타데이터·행동 값을 유지하고 새 대상 275개를 추가했다.
- AWS 100개의 직접 정책, 그룹 3개, 역할 3개, 그룹 소속과 역할 전환 설정을 함께 보존한다. Azure/GCP에는 해당 클라우드의 기존 정책 문법을 사용한다.
- 추가 대상에는 제한 권한, 넓은 정책, MFA/키 설정, 행동 이상을 혼합했다. 추가 설정은 이번 로컬 구현에서 설계한 것으로 논문에 실린 300개 실험이 아니다.
- 시드 42로 추가 행동 값을 재현한다. 300개의 전체 모집단으로 Isolation Forest를 다시 학습하므로 기존 25개의 AI 점수도 달라질 수 있다.
- 사용자 300개와 별도 역할 3개는 구분한다. 역할에 가상의 행동 로그를 만들어 AI 분석하지 않는다.

## 화면

1. `전체 분석`이 기본 화면이며 완료된 300개 결과가 바로 표시된다.
2. 대상 수와 BLOCK/ALERT/ALLOW, 대상별 R/A/G 및 최종 점수, 정책 원문·출처·판정 근거를 확인한다.
3. 클라우드·판정 필터, 대상별 상세, 역할 검사, 그룹 정책, 개선 권고, 저장 이력을 제공한다.
4. `전체 분석 실행·저장`은 현재 300개를 재분석하고 입력·결과를 로컬 DB에 새 행으로 저장한다. 과거 결과는 덮어쓰지 않는다.
5. `AWS 정책 분석`은 같은 300개 중 AWS 사용자 100개와 역할·그룹을 검사한다. 별도 예제나 이전 AWS 수집 파일 선택 메뉴는 없다. 이전 파일은 삭제하지 않고 보존한다.
6. 추가 전후 비교 화면·별도 예제 메뉴는 없다. 개선 권고는 현재 결과를 기준으로 표시한다.

## 파일

- `data/mock300.json`: 300개 통합 입력·AWS 원본·그룹/역할 연결.
- `data/mock300_aws.json`: 동일 입력의 AWS 정책 검사 원본.
- `validation/reports/mock300-analysis-report.json`: 현재 전체 분석 보고서.
- `validation/reports/mock300-analysis.csv`: 300개 대상 결과.
- `data/mock300.py`: 재현 가능한 입력 생성과 읽기.
- `analysis/current_dataset.py`: 현재 입력의 전체 분석과 저장.
- `visualization/current_dashboard.py`: 현재 결과 화면.

터미널 실행은 `python pipeline.py`가 현재 300개 입력을 사용한다. 기존 라이브러리의 명시적 `source="mock"`는 과거 25개 기준 회귀 검사용으로 보존한다. 새 입력은 `source="mock300"`로 읽는다.

## 결과 해석

첫 실행 결과: BLOCK 1, ALERT 47, ALLOW 252. 이는 현재 설계한 Mock와 분석 규칙의 결과이며 실측 성능이나 정확도가 아니다. 종합 점수 외에도 AI/그래프 단독 승격 규칙이 적용된다.

와일드카드·PassRole은 검토 후보다. 역할 정책은 사용자에게 자동 합산하지 않는다. 전체 유효 권한·역할 세션·다단계 권한 상승은 계산하지 않으며 실제 클라우드 권한을 변경하지 않는다. 그래프의 UNKNOWN 집계와 사용자 정책 묶음 기반 조치 시뮬레이션 한계는 이전 구현과 같다.
