- AWS 100개에 기존 그룹·역할 정책과 신규 사용자 소속/역할 설정 연결.
- 추가 전후 비교와 별도 예제 입력 선택 제거. 전체 분석이 기본 화면이며 현재 결과·근거·출처·역할·그룹·개선 권고를 표시.
- 현재 입력 재분석/DB 저장, 필터, 상세, JSON/CSV 내보내기 연결.

## 2026-10-26 — 기존 25개에 역할·그룹 정책 추가

- 기존 대상·메타데이터·행동을 보존하고 AWS 그룹 3개, 역할 3개, 사용자별 정책 및 연결 정보 추가.
- 그룹 소속 6건, 역할 전환 설정 3건. 역할 권한은 사용자 권한으로 자동 합산하지 않고 별도 검사.
- 기존 사용자 25개 전체 분석에 직접·그룹 정책을 실제 반영. 판정 ALLOW 20→16, ALERT 4→8, BLOCK 1 유지.
- 기존 예제 선택을 화면에서 제거하고 추가 전후 비교 및 대상별 정책 출처·역할 검사 결과로 교체.
- 새 분석의 기본 입력도 확장 데이터로 변경. DB 저장/복원 시 역할·그룹 원본과 연결 정보 보존.
- 새 설정은 논문 원본이 아니라 이번 로컬 구성이라는 점, UNKNOWN 매핑 한계와 공유 정책 조치 시뮬레이션 범위 명시.
- 설명: EXTENDED25_GUIDE.md. 입력과 전체 분석/CSV 보고서, 이전 버전 ZIP 보존.

## 2026-10-26 — 기존 DB 25개 전체 분석·검증

- 정책 사례 검증 기본 입력을 별도 예제에서 기존 DB 25개로 변경.
- 저장 입력으로 기존 전체 파이프라인 실행, 같은 입력의 과거 분석 결과 4개 표와 대상별 비교.
- 원본 입력·단계별 근거·조치 전후 결과·AWS 전용 후보 검사·논문 19개 항목 비교·JSON/CSV 다운로드 추가.
- 데이터 12 / 비교 실행 10 기준: ALLOW 20, ALERT 4, BLOCK 1. 이전 결과 25개 일치.
- 논문 비교는 수치·판정 17개 일치, 이름 대소문자 표기 2개 불일치. 이름 대응 관계를 명시하여 수치 비교.
- DB 읽기 전용 사용, 기존 25개 입력과 과거 결과 유지. 역할/그룹 연결 정보 부재는 검증 불가로 명시.
- 이전 결과를 일부러 바꾼 비교 검사에서 불일치 검출 확인.

## 2026-10-26 — 검증 실행 피드백 개선

- 재실행해도 같은 결과가 나와 버튼 반응을 구별하기 어려운 문제를 확인.
- 실행 중 표시, 완료 안내, 이번 접속의 실행 횟수, 한국 시간 기준 마지막 실행 시각 추가.
- 로컬 브라우저에서 두 차례 실행하여 횟수 1→2와 시각 갱신, 30개 통과 유지 확인.

## 2026-10-26 — 정책 사례 검증

- 합성 정책 입력·기대 결과·설명을 갖춘 30개 검증 사례 추가.
- 실제 검사기에 입력하여 개수·유형·Resource/Condition·출처 경로·거부 사유를 대조.
- 미지원/잘못된 입력 8개는 올바른 사유로 거부해야 통과.
- 기대값을 일부러 틀리거나 예상 밖 예외를 발생시키면 실패/오류로 표시되는 실행기 검사 추가.
- 별도 `정책 사례 검증` 메뉴: 실행, 분류/결과 필터, 사례 상세, 입력 JSON, JSON/CSV 보고서 다운로드.
- 보고서에 실행 시각·사례 버전·입력과 검사 코드 해시 기록. 코드 변경 시 재실행 안내.
- AWS Resource 누락/잘못된 형식과 Condition 객체 형식 검사를 보강.
- 역할 12 + 그룹 15 + 정책 사례 30 + 실행기 3 = 총 60개 관련 검사 통과.
- 화면 실행·필터·오류 사례 상세 및 기존 저장 결과 호환성 확인.
- 기존 Mock 결과표 4개는 앞서 보관한 ZIP DB와 비교해 일치. 원본 임시 폴더가 현재 비어 있어 이번에는 원본 위치의 소스 해시 재확인은 하지 못함.
- 25명 Mock와 판정식은 유지. 실제 AWS API·권한 변경 없음.

상세 설명: POLICY_VALIDATION_GUIDE.md. 이전 역할/그룹 단계 ZIP은 versions에 보존.

## 2026-10-26 — AWS 그룹 정책 연결

- 사용자의 GroupList를 그룹 본문에 연결하고 그룹 관리형·인라인 정책을 사용자 대상으로 분석.
- 그룹 자체를 별도 사용자로 계산하지 않으며 identity는 실제 소속 사용자 ARN을 유지.
- 그룹 ARN·그룹 이름·정책 출처·사용자 → 그룹 → 정책 경로를 정책·정규화·후보·DB에 보존.
- 같은 정책을 직접 받거나 여러 그룹/사용자를 통해 받는 경로를 구분하여 보존.
- 중복 그룹 가입 항목은 중복 계산하지 않고, 소속 사용자가 없는 그룹의 정책은 부여된 권한에 포함하지 않음.
- 그룹/정책 본문 누락·기본 버전 오류는 명시적으로 실패 처리.
- 그룹 예제와 연결 방식 필터 추가. 이전 사용자 전용/역할 전용 결과의 분석 범위 안내 유지.
- 저장된 합성 검증 데이터도 실제 AWS 수집 자료와 구분하여 표시.
- 그룹 검증 15개 추가. 기존 역할 검증 12개와 함께 총 27개 통과.
- 기존 실수집 파일은 그룹 0개이므로 그룹 기능은 별도 합성 예제로 검증.
- 기존 25명 Mock 데이터·판정식·실제 AWS 수집 파일은 변경하지 않음.

이전 역할 단계 ZIP은 versions/2026-10-26-aws-role-v1에 보존하고,
그룹 단계 적용용 ZIP은 원래 프로젝트 기준의 누적 변경 파일을 포함함.

## 2026-10-26 — AWS 역할 정책 분석

- 역할에 직접 연결된 관리형 정책의 기본 버전과 인라인 권한 정책을 추출.
- 사용자 기존 추출 함수는 유지하고 사용자·역할 통합 추출 진입점 추가.
- ARN, 대상 유형, 연결 유형, 정책 출처, 정책 버전, 인라인 정책 식별자를 결과에 보존.
- AssumeRolePolicyDocument는 권한 정책에 합치지 않음.
- 기존 Action 와일드카드·PassRole 후보 검사에 역할 정책 연결.
- 단일 객체 형태 Statement 지원. AWS 분석은 정규화 실패·NotAction/NotResource 미지원을 명시적으로 알림.
- 기존 사용자 분석 결과 유지 검증.
- 대시보드에 역할 정책 건수·유형 필터·역할 검증용 예제 추가.
- 기존 DB 결과는 사용자만 분석한 이전 결과임을 표시. DB 스키마는 변경하지 않음.
- Windows에서 DB 연결이 남지 않도록 저장·조회 후 연결을 명시적으로 종료.
